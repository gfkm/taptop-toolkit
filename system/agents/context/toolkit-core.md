# Toolkit core context

Read `../../AGENTS.md`, `../../README.md`, `../../docs/architecture.md`, and `../../docs/mvp-release-plan.md` before work. The Toolkit is isolated from the user’s existing Design Top system and `taptop-helper`; do not edit or import either as a runtime dependency.

The MVP promise is one user-selected JSON, automatic image upload, editable Taptop layers, literal reusable classes, and transparent progress. The source is public under the MIT License; there is no npm or Chrome Web Store release yet.
