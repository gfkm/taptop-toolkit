# Изолированное ядро Taptop Toolkit — первый этап

Исторический план первого этапа (2026-10-02). Некоторые пути и ограничения ниже относятся к состоянию до переноса в `system/` и выделения импортёра. Текущий план и фактический статус см. в the maintainers' development plan (`system/docs/superpowers/`, kept out of the distribution).

Основание: пользователь одобрил архитектуру и начало реализации 2026-10-02.

Цель: получить переносимую папку инструментов и пустой проект, не меняя существующий MVP.
Граница записи: только taptop-toolkit/. Старые файлы, индекс Git, Helper и настройки Obsidian не менять.

Архитектура: самостоятельная копия минимального графа зависимостей HTML→IR→Taptop; проектные стили передаются входными данными. Никаких импортов из родительского репозитория. Node.js >=22, parse5, postcss. Публикация и лицензирование — отдельный этап.

- [x] Сначала интеграционные тесты: новый пустой проект, отказ перезаписывать существующую папку, компиляция нейтрального HTML, внешняя типографика, неизвестная версия, неподдерживаемая интерактивность.
- [x] Скопировать только универсальные модули и контракты; сохранить происхождение и контрольные суммы. Удалить зависимость компилятора от встроенной типографики, получать классы типографики из переданных CSS.
- [x] Добавить безопасные команды init и compile. Проект содержит namespace, закреплённую версию, пустой реестр и папки источников/результатов. Все входы компиляции ограничены корнем проекта; существующие результаты не перезаписываются.
- [x] Проверить сквозную сборку статичной секции и машинную валидацию пакета. Перенос изображений через CLI, автоматический Figma-импорт и новое расширение не заявлять готовыми.
- [x] Запустить унаследованные автономные тесты, новые тесты и smoke test из папки вне исходного проекта. Сверить исходные файлы по SHA-256.
- [x] Записать README, границы поддержки и последующие этапы.

Следующие самостоятельные этапы: собственный импортёр и транспорт расширения; навык и Figma-режимы; три независимых внешних пилота; публичный релиз с выбранной лицензией.
