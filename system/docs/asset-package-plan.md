# Архив: двухчастный пакет ресурсов

Этот ранний план описывал JSON рядом с каталогом `*-assets/`. Он заменён и не
должен использоваться ни в интерфейсе, ни в новых интеграциях.

Текущий контракт — один JSON версии 2: бинарные изображения находятся в
`wrapper.embeddedAssets`, а узлы изображений ссылаются на них через
`__pendingUpload.assetKey`. Пакеты версии 1 отклоняются с инструкцией
пересобрать экспорт.

Описание действующего формата: [asset-package-design.md](asset-package-design.md).
