# Переносимые ресурсы — актуальный формат одного JSON

Ранее использовались JSON и соседний каталог `имя-assets/`. Этот формат версии 1
выведен из использования: импортёр возвращает понятную ошибку и просит пересобрать
пакет. Историческое решение ниже заменено форматом версии 2.

## Цель

Добавить к изолированному Taptop Toolkit перенос изображений между компьютерами без ссылок на локальный сервер, абсолютных путей или идентификаторов медиатеки Taptop.

## Решение

Команда `compile` получает HTML с `<img>` и создаёт один JSON версии 2. Байты каждого
изображения находятся в `wrapper.embeddedAssets` как каноническая Base64-строка.
Запись содержит стабильный ключ, SHA-256 исходных байтов, MIME type, длину и размеры.
Одинаковые байты представлены одной записью. Узел изображения хранит только
`__pendingUpload.assetKey`, ссылающийся на эту запись.

Конвертер не создаёт localhost URL и не запускает сервер. Пакет не содержит Taptop media IDs. Импортёр декодирует байты, сверяет длину и SHA-256, загружает изображение в целевой проект и записывает выданный media ID только в локальный receipt.

## Входные данные и ограничения

Поддерживаются локальные относительные `src` изображений из папки проекта. URL, data URL, SVG, CSS `url()`, srcset и изображения вне корня проекта блокируются. На первом этапе разрешены PNG, JPEG, WebP и GIF. Размеры PNG определяются без дополнительной зависимости; JPEG/WebP/GIF получают размеры только при поддержке в встроенном reader, иначе сборка останавливается. Файл должен существовать, быть обычным файлом и совпадать с форматом, заявленным расширением.

Повторяющиеся байты представлены одной записью. Существующий JSON не перезаписывается.
Проверка пакета декодирует каждую запись, сверяет Base64, длину, SHA-256 и ссылки из узлов.

## Границы

Этот этап не реализует загрузку в Taptop, не объявляет изображение живьём импортированным и не меняет taptop-helper. Поведения, Figma-извлечение и CSS background-image остаются отдельными этапами.

## Проверки

Интеграционные тесты покрывают успешный PNG-пакет, дедупликацию одинаковых байтов,
попытку выхода за корень проекта, неподдерживаемый формат, некорректную Base64,
несовпадение длины/хеша и отказ перезаписать JSON.
